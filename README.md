This project uses **IBM Watson Natural Language Understanding (NLU)** and **TF-IDF** to analyze and summarize articles related to **Sports Medicine**.  
It highlights the most important words, topics, and insights from the text.

## What it does
- Cleans and preprocesses text (removes stopwords, punctuation, etc.)
- Extracts top keywords using **TF-IDF**
- Uses **IBM NLU API** to get concepts, entities, and keywords
- Generates a **WordCloud** for visual summaries

## Tools Used
Python · NLTK · Scikit-learn · IBM Watson NLU · BeautifulSoup · WordCloud
